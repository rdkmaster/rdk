示例2: 使用服务来提供数据

本例中，服务返回的数据节点为module，而默认的是node，此时可以通过node_field来修正




HTML代码： <rdk_tree node_field="module" label_field="label" data="ds_tree_data" ds="ds_tree_data" ds_url="/demo/mock_data/tree_data" ds_query_if="ready"> </rdk_tree>


示例3：事件回调

HTML代码： <rdk_tree data="treeData" rdk_click="clickHandler" rdk_double_click="doubleClickHandler"></rdk_tree> JS代码： scope.clickHandler = function(event, treeNode) { console.log("click callback!" + treeNode.label); } scope.doubleClickHandler = function(event, treeNode) { console.log("doubleclick callback!" + treeNode.label); }

示例4：自定义节点的需通过draggable设置拖动功能






HTML代码： <-- 方式1：不需要修改可拖动属性时，使用下面方式最简便 --> <rdk_tree draggle data="treeData"></rdk_tree> <-- 方式2：需要修改可拖动属性时，使用下面方式 --> <rdk_tree draggle="dragMode" data="treeData"></rdk_tree> JS代码 scope.dragMode = true; scope.toggleDraggable = function() { scope.dragMode = !scope.dragMode; console.log('scope.dragMode='+scope.dragMode); }
